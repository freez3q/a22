A22 Dental Clinic — статическая HTML-версия сайта

Как открыть локально:
1. Распакуйте архив.
2. Откройте файл index.html двойным кликом в браузере.

Структура:
- *.html — страницы сайта.
- _next/ — собранные CSS/JS/шрифты и анимации из Next.js. Не удалять.
- images/ и файлы изображений в корне — медиа сайта.

Служебные .txt файлы и дублирующие папки страниц удалены.
